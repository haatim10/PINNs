This paper studies physics-informed neural networks (PINNs) for a time-fractional integro-differential equation with weakly singular memory terms, and benchmarks classical PINNs against quantum-inspired TE-QPINN surrogate variants under fairness-controlled protocols. We evaluate architecture stabilization strategies, memory-aware analytic feature extensions, multi-seed confirmatory performance, paired statistical significance, and alpha/beta robustness. We also include an optional exact PennyLane TE-QPINN feasibility check and application-inspired sparse CSI forecasting demonstrations in scalar and two-channel settings. % TODO: Insert final quantitative highlights from Table~\ref{tab:confirmatory10} and Table~\ref{tab:stats10}.
\end{abstract}

\section{Introduction}
% TODO: Finalize motivation and novelty framing using contribution list from final_report_inventory.md.
Fractional and memory-dependent differential systems remain challenging for neural PDE solvers due to nonlocal operators and optimization stiffness. This work extends a baseline fractional PINN pipeline with TE-QPINN-inspired surrogate models, stabilization and ablation studies, memory-aware feature engineering, and a fairness-controlled multi-seed evaluation protocol.
Foundational context draws from PINNs \cite{PINNs}, fractional calculus and Caputo operators \cite{FracCalc}, L1-style discretization \cite{L1Scheme}, and product-integration treatment of weakly singular memory terms \cite{ProductIntegration,FracPINN}. The quantum-inspired track is motivated by hybrid QNN/QPINN directions \cite{QNN,QPINN,TEQPINN}.

\subsection*{Main Contributions}
\begin{itemize}
    \item Reproducible benchmark framework for a time-fractional integro-differential PINN problem.
    \item TE-QPINN-inspired surrogate implementation with modular configuration support.
    \item LayerNorm/residual/gated/ablation experiments under locked protocols.
    \item Memory-aware analytic feature extension with classical-memory fairness control.
    \item 10-seed confirmatory analysis with paired statistical tests.
    \item Alpha/beta robustness validation.
    \item Exact PennyLane TE-QPINN feasibility study (differentiability + bottleneck analysis).
    \item Application-inspired sparse CSI forecasting demos (scalar and two-channel).
\end{itemize}

\section{Fractional Integro-Differential Problem Formulation}
We consider the baseline problem
\begin{equation}
    D_t^\alpha u(x,t) - (x^2+1)u_{xx}(x,t) +
    \int_0^t \sin(x)(t-s)^{-\beta}u(x,s)\,ds = f(x,t),
\end{equation}
with $x\in[0,1],\, t\in(0,1]$, boundary conditions
\begin{equation}
u(0,t)=t^\alpha,\quad u(1,t)=-t^\alpha,
\end{equation}
and initial condition
\begin{equation}
u(x,0)=0.
\end{equation}
